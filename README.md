# 빅데이터 수치해석 2026 실습

2026년 **빅데이터 수치해석** 수업의 실습 자료를 정리한 저장소입니다.

Python과 Jupyter Notebook을 활용하여 수치해석의 주요 개념을 직접 구현하고, 데이터 분석 및 시각화 문제에 적용합니다.

## 실습 내용

| 실습 | 주제 | Notebook |
|---|---|---|
| 1 | NumPy, Matplotlib | `빅데수_실습1_Numpy,_Matplotlib_(2026).ipynb` |
| 2 | SVD, PCA, Eigen Face | `빅데수_실습2_SVD,_PCA,_Eigen_Face(2026).ipynb` |
| 3 | Principal Axes, Eigen Face, Denoising | `빅데수_실습3_Principal_Axes,_Eigen_Face,_Denoising(2026).ipynb` |
| 4 | Least Squares, Regression, Numerical Solution of Equations | `빅데수_실습4_Least_Squares,_Regression,_Numerical_Sol_(Root_of_Equ).ipynb` |
| 5 | 중간고사 대비 수업 노트 및 실습문제 풀이 | `빅데수_실습5_중간대비(수업 노트) 실습문제 정답(2024풀이).ipynb` |
| 6 | Vector Calculus, Interpolation | `빅데수_실습6_Vector_Cal_Interpolation_(2026).ipynb` |

## 주요 학습 내용

- NumPy를 이용한 벡터 및 행렬 연산
- Matplotlib을 이용한 데이터 시각화
- Singular Value Decomposition (SVD)
- Principal Component Analysis (PCA)
- Eigen Face와 주성분 기반 이미지 표현
- Principal Axes와 차원 축소
- SVD/PCA를 활용한 Denoising
- Least Squares와 Regression
- 비선형 방정식의 수치적 해법
- Vector Calculus
- Interpolation

## 실행 환경

실습 파일은 Jupyter Notebook 형식(`.ipynb`)입니다.

다음 환경에서 실행할 수 있습니다.

- Jupyter Notebook
- JupyterLab
- Visual Studio Code + Jupyter Extension
- Google Colab

로컬에서 실행하려면 저장소를 복제합니다.

```bash
git clone https://github.com/jooyongsim/numerical2026.git
cd numerical2026
```

이후 Jupyter를 실행합니다.

```bash
jupyter notebook
```

## 수업 실습 방법

1. 해당 주차의 Notebook을 엽니다.
2. 설명과 수식을 확인합니다.
3. 코드 셀을 순서대로 실행합니다.
4. 결과와 그래프를 확인합니다.
5. 예제의 조건이나 데이터를 변경하면서 결과가 어떻게 달라지는지 실험합니다.
